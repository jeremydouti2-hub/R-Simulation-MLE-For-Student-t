# Maximum Likelihood Estimation of the Parameters of Student’s t Distribution under SRS and RSS

This project investigates the performance of Maximum Likelihood Estimators (MLEs) for the two-parameter Student’s t-distribution under:

- Simple Random Sampling (SRS)
- Ranked Set Sampling (RSS)
- Multi-cycle Ranked Set Sampling (RSS2)

The study compares the estimators using:

- Bias
- Mean Squared Error (MSE)
- Relative Efficiency (RE)

## Methods

- Monte Carlo Simulation
- EM Algorithm
- Ranked Set Sampling
- Student’s t-distribution
- Maximum Likelihood Estimation

## Technologies

- R Programming
- LaTeX
- Git/GitHub


## Main Results

The simulation study shows that RSS and RSS2 outperform SRS in terms of:

- Lower bias
- Lower Mean Squared Error
- Higher Relative Efficiency

The efficiency gain increases with sample size and number of RSS cycles.
